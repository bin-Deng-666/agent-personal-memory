# Personal Memory for Pi

The Pi package of [Agent Personal Memory](https://github.com/bin-Deng-666/agent-personal-memory). Includes the Pi interface and the common memory core, with no Claude Code hooks or MCP server.

```sh
pi install git:github.com/bin-Deng-666/agent-personal-memory
```

Reload/restart Pi and open `/personal-memory`. The repository's Pi manifest routes to this package. For a local checkout, use `pi install /absolute/path/to/agent-personal-memory/packages/pi`.
