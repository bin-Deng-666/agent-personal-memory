# Personal Memory for Claude Code

The Claude Code package of [Agent Personal Memory](https://github.com/bin-Deng-666/agent-personal-memory). Includes its standalone runtime, hooks and native menu commands, with no Pi runtime or SDK dependency.

Run in Claude Code:

```text
/plugin marketplace add bin-Deng-666/agent-personal-memory
/plugin install agent-personal-memory@agent-personal-memory
```

Restart Claude Code, run `/agent-personal-memory:setup` once, then restart and use `/personal-memory`. The namespaced `/agent-personal-memory:personal-memory` is available without installing the shortcut. Claude's built-in `/memory` remains available.
